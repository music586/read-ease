# Chrome 阅读模式插件设计

日期：2026-07-31  
状态：已批准

## 1. 产品目标

设计一款面向新闻、博客、公众号文章等单篇长文的 Chrome 扩展。用户可在当前网页中进入沉浸式阅读模式，插件提取并清洗正文，通过稳定、可定制的版式重新展示内容。

第一版完全在本地处理网页，不上传正文、不要求账号，也不依赖服务器。设计为未来可增加由用户主动启用的云端 AI 备用提取器，但该能力不属于第一版。

## 2. 成功标准

- 用户可通过扩展图标或快捷键进入和退出阅读模式。
- 在选定的中英文新闻与博客样本中，大多数页面能一键获得结构完整、无明显广告噪声的正文。
- 图片、链接、引用、列表、代码块和表格得到保留。
- 导航、广告、评论、推荐阅读、悬浮按钮和无关交互组件得到移除。
- 退出阅读模式后，原网页不刷新，滚动位置和页面状态不受影响。
- 通用提取失败时，用户可点选正文并保存为可复用的网站规则。
- 排版设置同时支持全局默认值和网站覆盖值。

验收所用的网页样本清单在实施计划中确定，并同时覆盖静态页面、SPA 页面、中文文章和英文文章。

## 3. 第一版范围

### 3.1 包含

- 通用正文提取与安全清洗
- Shadow DOM 全屏阅读层
- 当前页覆盖式阅读体验
- 极简 `Aa / ×` 控制区
- 浅色、米色和深色主题
- 字体、字号、字间距、行距、段间距、版心宽度和页面边距设置
- 全局排版设置和网站排版覆盖
- 用户网站规则、内置网站规则和高级 CSS Selector
- 可视化点选正文、标题和排除区域
- 按域名及可选路径保存规则
- 为已授权网站开启自动阅读模式
- 提取失败后的手动选择、规则回退和重试

### 3.2 不包含

- 账号、云同步和云端 AI
- 稍后阅读、收藏、批注和笔记
- 小说章节导航和自动翻页
- PDF 阅读模式
- Firefox、Safari 等其他浏览器
- 自动摘要、翻译和朗读

## 4. 技术方案

采用 Chrome Manifest V3、TypeScript 和 Shadow DOM。Content Script 从当前页面提取正文，清洗后将阅读视图挂载为全屏 Shadow DOM 覆盖层。原页面保留在覆盖层下方，退出时直接移除覆盖层并恢复进入前的状态。

该方案相比直接替换页面 DOM，能更可靠地保留 SPA 状态、播放器、表单和滚动位置；相比使用扩展页面或 iframe，能减少跨上下文通信及图片、链接、文本选择和页面定位问题。

## 5. 系统架构

### 5.1 页面控制器

页面控制器运行在 Content Script 中，负责：

- 进入和退出阅读模式
- 挂载和卸载 Shadow DOM 阅读层
- 保存与恢复滚动位置
- 监听快捷键
- 协调提取、清洗、规则匹配和渲染
- 处理 SPA 导航和本次页面的自动进入抑制状态

页面控制器不包含正文识别或配置持久化的具体实现。

### 5.2 正文提取器

正文提取器输入页面 DOM 和已匹配规则，输出统一文章数据：

- 标题
- 作者
- 发布时间
- 来源域名和原始 URL
- 主图
- 正文 HTML
- 预计阅读时间
- 提取来源及质量信息

通用提取采用 Mozilla Readability 类型的本地启发式算法。提取器通过稳定接口调用，未来可增加其他本地算法或由用户主动启用的云端备用提取器。

### 5.3 内容清洗器

内容清洗器接收提取出的 HTML，并输出可安全渲染的文章内容：

- 删除脚本、表单、事件处理器、广告和危险属性
- 删除评论、推荐阅读和无关交互区域
- 保留段落、标题、图片、链接、引用、列表、代码块和表格
- 将相对图片及链接地址转换为绝对地址
- 阻止原网页脚本进入阅读视图

### 5.4 阅读视图

阅读视图只接收清洗后的文章数据和解析后的排版配置，不直接读取原网页。视图运行在 Shadow DOM 中，避免原站样式污染。

### 5.5 规则引擎

规则引擎负责：

- 根据域名和路径匹配规则
- 合并内置规则和用户规则
- 解析正文、标题、作者、日期、主图及排除区域 Selector
- 校验用户规则
- 决定网站是否自动进入阅读模式

### 5.6 设置存储

第一版使用 `chrome.storage.local` 保存：

- 全局排版
- 网站排版覆盖
- 用户网站规则
- 网站自动进入设置
- 一次性引导状态

内置规则随扩展版本发布，不写入用户配置。未来若加入跨设备同步，可选择性迁移体积较小的配置到 `chrome.storage.sync`。

## 6. 数据流

手动进入阅读模式：

1. 用户点击扩展图标或触发快捷键。
2. 页面控制器读取 URL，并请求规则引擎匹配规则。
3. 正文提取器按规则优先级生成文章数据。
4. 内容清洗器清理正文并转换资源地址。
5. 页面控制器读取并合并全局排版与网站覆盖。
6. 阅读视图在构建完成后一次性显示。

自动进入阅读模式：

1. 用户提前为特定网站开启自动进入，并授予对应站点权限。
2. 页面导航完成后，控制器等待 DOM 达到稳定条件。
3. URL 必须匹配已配置的域名和路径规则。
4. 提取结果必须达到最低质量阈值。
5. 通过检查后进入阅读模式。
6. 若用户主动退出，同一页面生命周期内不再自动触发。

## 7. 正文提取与规则优先级

规则按以下优先级执行：

1. 当前页面的临时修正
2. 用户保存的网站规则
3. 插件内置的网站规则
4. 通用正文提取算法

规则可匹配整个域名或指定路径，例如：

- `example.com/*`
- `example.com/news/*`
- `example.com/article/*`

每条用户规则可包含：

- 正文 Selector
- 标题、作者、日期和主图 Selector
- 多个排除区域 Selector
- 是否自动进入阅读模式
- 网站排版覆盖项
- 创建方式和更新时间

用户规则失效时，插件回退到内置规则或通用提取，并提示该规则需要修正。失效规则不会阻断阅读。

## 8. 规则编辑体验

用户从阅读模式的胶囊菜单进入“修正此网站”：

1. 临时关闭阅读层并显示原网页。
2. 鼠标悬停时高亮可选元素。
3. 用户选择正文区域。
4. 用户可选择标题区域。
5. 用户可选择多个排除区域。
6. 插件实时预览提取结果。
7. 用户选择仅本次使用、整个网站或指定路径范围。
8. 校验通过后保存并重新生成阅读视图。

高级用户可直接编辑 CSS Selector。正文 Selector 必须命中合理内容；禁止将 `html`、`body` 等过宽元素直接保存为正文区域。无效 Selector、空正文或明显过短的正文不能保存为有效规则。

## 9. 阅读界面

阅读层为居中单栏版式。顶部显示标题、作者、发布时间、来源域名和预计阅读时间。默认界面只在右上角显示极简胶囊：

`Aa　×`

- `Aa` 打开紧凑排版浮层。
- `×` 退出阅读模式。
- `Esc` 快捷退出阅读模式。
- 点击正文空白处收起排版浮层。

排版浮层包含：

- 浅色、米色和深色主题
- 字体
- 字号
- 字间距
- 行距
- 段间距
- 正文宽度
- 页面边距
- “仅此网站使用这些设置”开关
- 恢复默认设置

设置变更即时预览并自动保存。首次进入阅读模式时可显示一次轻量引导，之后不再自动出现。

## 10. 配置继承

全局排版是所有网站的默认值。网站覆盖只保存用户实际修改过的属性，其他属性继续继承全局设置。

配置解析顺序为：

1. 内置默认排版
2. 用户全局排版
3. 当前网站覆盖项

恢复网站默认值时只删除网站覆盖项，不影响用户全局排版。

## 11. 权限与隐私

第一版权限：

- `activeTab`：用户主动启动时读取当前网页
- `storage`：保存设置和规则
- `scripting`：按需注入阅读控制器
- `commands`：支持快捷键
- 可选站点权限：仅在用户为某网站开启自动进入时申请

默认不申请访问所有网站的永久权限。用户主动启动时，通过 `activeTab` 获得当前页面的临时访问权。自动进入仅对用户明确授权的域名生效。

隐私约束：

- 网页正文不上传
- 不收集浏览历史
- 不加载远程执行代码
- 设置和规则默认保存在本机
- 将来增加云端 AI 时，必须由用户单独开启，并在发送内容前明确提示

## 12. 页面生命周期与性能

插件支持传统页面和 SPA：

- 监听 History API 导航及必要的 URL 变化
- 导航后等待 DOM 稳定，但设置明确超时
- 仅在手动触发或已授权自动模式下执行提取
- 阅读层开启后停止观察无关 DOM
- 避免持续扫描、轮询或后台解析整个页面

进入阅读模式时，可暂停与阅读无关且会持续干扰的背景媒体；退出时恢复插件主动改变的状态。插件不尝试控制无法安全恢复的页面内部状态。

## 13. 异常处理

所有异常遵循“不破坏原网页”原则：

- 阅读层构建完成后才显示。
- 提取、清洗或渲染失败时保留原页面。
- 正文为空或低于质量阈值时不展示空白阅读层。
- 提取失败时提供重新尝试、手动选择正文、查看高级规则和取消操作。
- 单张图片加载失败时显示占位提示，不阻断全文。
- 退出时移除阅读层，并恢复滚动位置和插件主动修改的页面状态。

## 14. 测试策略

### 14.1 单元测试

- 域名与路径规则匹配
- 规则优先级及回退
- 全局配置与网站覆盖合并
- HTML 清洗和危险属性删除
- 相对资源地址转换
- 文章数据转换和阅读时间计算

### 14.2 提取样本测试

保存具有代表性的新闻与博客 HTML fixture，验证：

- 标题和元数据提取
- 正文长度与段落结构
- 图片、列表、引用、代码块和表格保留
- 广告、评论和推荐内容移除
- 无效用户规则正确回退

### 14.3 组件测试

- 排版控件和即时预览
- 三种主题
- 配置继承与恢复默认
- 规则编辑和 Selector 校验
- 提取失败提示

### 14.4 Chrome 端到端测试

- 手动进入和退出
- 滚动位置恢复
- 原页面状态保留
- SPA 导航
- 自动进入及退出后抑制
- 可视化点选规则
- 站点权限申请与拒绝
- 用户规则失效后的回退

## 15. 后续扩展边界

后续能力通过现有模块接口扩展：

- 云端 AI 是新的可选提取器，不侵入阅读视图。
- 云同步是新的设置存储后端，不改变规则或排版模型。
- 收藏、笔记和朗读属于独立产品子系统，不纳入第一版实现计划。
